## Slide 4 — How It Works (Data Flow)

**Headline:**
Seamless Intelligence in Action

**Content:**
1.  **Input:** User interacts via the Next.js React frontend.
2.  **Real-Time Connection:** Socket.IO tracks live presence via Redis.
3.  **Intent Engine:** AI module processes the request via external LLMs.
4.  **Smart Execution:** Next.js backend queries PostgreSQL via Prisma or connects to Banking APIs.
5.  **Response:** The system formulates and delivers a highly accurate response instantly.

**Suggested Visual:**
A minimalist flowchart with glowing, animated neon arrows connecting nodes (Next.js Frontend -> Socket.IO & Redis -> LLM -> Prisma & DB -> Frontend). Use modern tech iconography for each node.

**Animation Recommendation:**
Flow path animation (light traveling along the arrows) to show the speed and direction of data processing.

**Presenter Notes:**
"Here is the architecture in action. Interactions are processed in real-time. Whether it's tracking active users through Redis or querying account data from our mock Banking API, the flow is secure and instantaneous."

## Slide 7 — Technology Stack

Built on Modern Architecture
